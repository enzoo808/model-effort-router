## Method

- **Agents:** a preflight agent first answered `claude-sonnet-5-5`; 10 first-pass fresh Sonnet 5.5 agents (Agent tool,
  `model: sonnet`) plus two re-run agents. All 78 result files start with `MODEL: claude-sonnet-5-5`.
- **Batches:** generated by script (`~/model-secici-iter39/cold_plan.py`, outside the repo) from `evals/routing/evals.json`, 53 ids each
  exactly once, 8-8-8-8-7-7-7: 1 `a1 s0a a2 a3 a4 a5 s0b b1` · 2 `b2 c1 c2 c3 o2 o3 d1 e1` · 3 `f1 g1 h1 i1 j1 k1 k2 l1` ·
  4 `m1 n1 o1 p1 q1 r1 t1 u1` · 5 `sc1 dr1 da1 dg1 kw1 v1 x1` · 6 `y1 z1 w1 w2 w3 w4 fa1` · 7 `ter1 al1 ar1 tg1 tg2 tg3 tg4`.
  Turkish (24, the iteration-38 set): `c2 c3 d1 g1 i1 j1 k1 k2 | l1 p1 t1 sc1 dr1 da1 dg1 v1 | z1 w1 w2 w3 fa1 ar1 tg1 tg2`.
- **Isolation:** a temp directory outside the repo held only the 4-file install set (`SKILL.md`, `opencode-benchmarks.md`,
  `opencode-evidence.json`, `reference.md`) and `batches/` (ids and prompts only); Turkish: a second directory with only
  `instructions.tr.md` and `tr-<N>.txt`. Agents were told to read nothing else and not to use the Skill tool.
- **Re-runs:** each failing eval once in a new fresh agent (`da1` English; `c2` Turkish). `j1` and the `/fast` omissions were not re-run.
- **`/fast` grading copies:** `tr-router/fast-copies/` holds copies of the raw Turkish files with the declared
  `⚡ Claude /fast available (2.5x faster, 2× price).` line appended **only** to the eight files whose sole raw failure was that
  missing line (`d1 i1 t1 sc1 v1 w2 fa1 ar1`; `i1` also gets ` Opus 4.8 fast mode ends 30 Nov 2026.`). Raw files are untouched.
